# Sponsor Android MoE Engine

I am seeking sponsorship to keep developing storage-backed LLM inference on Android phones. The project has run a quantized 35B MoE artifact through a native text API on an 8 GB Snapdragon 665 phone. It is experimental, and its current latency and qualification gaps are documented in the [benchmark record](docs/BENCHMARKS.md).

## What support would fund

- Faster startup, expert reads, and CPU execution, measured against the same artifact and device.
- A reference machine with enough memory to compare the real 35B output against the pristine backend.
- Android devices across CPU, RAM, and storage classes for independent compatibility testing.
- Sustained workloads, cancellation/recovery testing, and reproducible build and evidence tooling.
- Maintainer time for documentation, issue triage, and reviewing contributions.

Financial support, loaned or donated hardware, reference-compute access, and engineering contributions are welcome. Sponsorship does not imply a guaranteed speed target, feature deadline, or production support agreement.

## Start a conversation

[Open a sponsorship inquiry](https://github.com/Ananthzeke/android-moe-engine/issues/new?template=sponsorship.md) with the type of support you can offer. GitHub issues are public; do not post payment information, credentials, or private contact details. The inquiry starts a discussion with the repository maintainer.

There is no active payment page or GitHub Sponsors payout profile linked here. A payment method can be added after the maintainer configures it. The repository's Sponsor link leads to this page.
